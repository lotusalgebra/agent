Welcome to the LOTUS Agent Child installer

This installer puts the LOTUS Child worker onto this Mac. Once installed, the child can be discovered by a LOTUS mother on the same local network and will accept work (parsing, review, archiving) from it.

What will be installed

  • /Applications/LOTUS Child/ — bundled binary + runtime
  • A launcher in Applications you can double-click
  • A configuration wizard accessible from the same launcher

After install

  • The configuration wizard will ask for the mother's IP and shared token.
  • Copy the token from the mother at ~/.lotus_auth/token.txt.
  • Once configured, the child announces itself via Bonjour and the mother picks it up automatically.
